# Meridian art — Gemini prompts

Save each image as `.webp` in this folder with the exact file name. The lab picks them up automatically (until then it falls back to plain colours and initials).

Shared style line (paste at the end of every prompt):
> painterly sci-fi concept art, calm and elegant, soft cinematic light, muted palette, high detail, no text, no logos, no people unless described
