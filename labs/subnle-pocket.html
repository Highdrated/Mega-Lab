The /24 – /30 ladder
CIDROctetWildBlockHosts
  • Block = 256 − mask octet. Networks start at multiples of it.
  • Broadcast = next network − 1. Hosts = 2host bits − 2.
  • One prefix shorter = double the block. /16–/23 → same tricks in the 3rd octet.
  • Split: borrowed bits b → 2b subnets. Summarise: 2k networks → prefix − k.
  • RFC 1918: 10/8 · 172.16/12 (16–31) · 192.168/16. Also 127/8 loopback, 169.254/16 link-local, 100.64/10 CGNAT.
