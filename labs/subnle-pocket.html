The cheat row

Write this from memory before any exam question. Then read straight down a column.

block1286432168421
mask128192224240248252254255
prefix/25/26/27/28/29/30/31/32

/27 → block 32, mask 224. Top row: halve. Middle row: running total. Bottom row: count up.

trick 2

Round down, like with tens

Rounding 37 down to tens gives 30. Rounding down to 32s gives 32. That's the network.

0·32← 37 lands here ·64

Broadcast = the next multiple − 1 → 64 − 1 = 63.

trick 3

Even / odd check

Network address → always even. Broadcast → always odd. Got .33 as a network? Wrong, recalculate.

trick 5

Count on your fingers

A /27 has 8 blocks = 8 fingers, no thumbs. Count by 32. Where does .100 go? 0, 32, 64, 96… the next finger is 128, too far. So: finger 4 → .96.

cheat card
The /24 – /30 ladder
CIDROctetWildBlockHosts
  • Block = 256 − mask octet. Networks start at multiples of it.
  • Broadcast = next network − 1. Hosts = 2host bits − 2.
  • One prefix shorter = double the block. /16–/23 → same tricks in the 3rd octet.
  • Split: borrowed bits b → 2b subnets. Summarise: 2k networks → prefix − k.
  • RFC 1918: 10/8 · 172.16/12 (16–31) · 192.168/16. Also 127/8 loopback, 169.254/16 link-local, 100.64/10 CGNAT.
